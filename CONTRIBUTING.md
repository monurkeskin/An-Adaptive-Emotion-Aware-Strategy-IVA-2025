# Contributing

Read [docs/development.md](docs/development.md) for the independent tests, code
boundaries and a test-first example. Check [METHOD.md](METHOD.md) before changing
scientific behavior. Include a minimal synthetic fixture, actual engine version,
configuration and expected/observed outcome in an issue or pull request.

Keep original source and contributor notices. Record method/protocol/metric changes
explicitly and validate the pinned engine upgrade with this companion's own suite.
